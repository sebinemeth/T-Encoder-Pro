T-Encoder UI mockups

Proposed dark, AMOLED-first design for the 390×390 round panel. Pure black background, state-colored accents, one idea per screen. These are SVG renderings of the layouts in PLAN_ui_upgrade.md, not device captures.

The first light tile under All tiles is clickable: tap the disc to toggle it, as touch (or an encoder press) does on the device.

All tiles

Edit mode

Entered with an encoder press on cover, thermostat and fan. The ring thickens and the value being edited takes the accent color (the hero is already 56 px, so its size does not change). Today it only adds a knob ring.

Page indicator

Dots follow the bottom bezel up to 12 entities. Beyond that they would crowd the cover buttons and the toast, so they are replaced by an n / N caption in the same place.

System states

AMOLED idle dimming

After a period without input the panel fades to a low brightness (here about 28%) so static shapes burn less. Any encoder or touch input restores it.
